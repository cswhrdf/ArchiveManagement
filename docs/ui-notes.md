## 游戏主页（游戏库分区）

**原文案**（曾显示在主页顶部页签右侧，`home.hint`，已从界面移除）：集中查看全部游戏并按状态筛选: 待处理 = 还没有配置存档位置或存档路径已失效。同一时刻只有一款游戏处于启用状态, 快捷键与定时备份只对启用的游戏生效; 归档后只保留删除、导出、取消归档与打开详情。

**为什么移出**：这段说明挤在页签右边，窗口不宽时左侧文字会被裁掉；页面本身应当清爽，规则类说明更适合放在文档/帮助里。

**要点整理**（wiki 版建议按这三条展开）：

- **待处理**：还没有配置存档位置，或者已有的存档路径已失效（迁移了游戏目录、删掉了存档文件夹时会出现）。
- **同一时刻只有一款游戏启用**：全局快捷键与定时备份只对启用的游戏生效；切换到另一款启用时，原来那款会自动停用。
- **归档**：归档的游戏只保留"删除游戏、导出游戏、取消归档、打开详情"四项操作，其它操作入口全部收起。
