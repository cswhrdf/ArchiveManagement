# 全局快捷键

快捷键用于在游戏内快速操作：**全局保存**立即为当前游戏创建一次备份，**创建分支**在选中节点上分出一条新分支。各平台的权限差异见 [platforms.md](platforms.md)。**快捷键只对当前启用的那款游戏生效**：停用或已归档的游戏不会触发（只给出一条提示），避免误按到不相关的游戏上。

## 默认键位

- **默认组合键是 `Win+Alt+S`（保存）与 `Win+Alt+F`（创建分支）**：`Win` 键在Windows/Linux 上是 Win/Super、在 macOS 上是 Command，因此三个平台的键位完全一致；字母都选在键盘左下角，一只手就能按下。分支键是踩坑换出来的：`Z`（首个默认）与 NVIDIA App / GeForce Experience 的覆盖层（`Alt+Z`）冲突；`B`/`G`/`R`/`M` 被 Windows 自带的 Xbox Game Bar 占用（蓝牙配对 / 打开 Game Bar / 录制 / 麦克风）；最终选 `F`（Fork，分支）——同样单手可及且无已知占用。**旧配置文件里已经保存的组合键不受换默认影响**，仍在用冲突键位的，去"设置"里重新录制即可。
- **创建分支的快捷键不弹窗也不看选中**：触发时直接用默认分支名（中文"分支"/`Branch`）在**当前节点**（带 `●` 的那个）上分出一支——快捷键是在游戏里按的，不应要求先回界面选中一个节点；界面上"从此处创建分支"按钮仍以**选中节点**为父。游戏还没有任何备份时按快捷键会给一条提示（不会悄悄没反应）。**分支不受"存档未变化"限制**，无论内容是否与起点一致都会创建。**全局保存遇到"存档没有变化"时静默跳过**（与自动备份同口径，不弹窗不提示，只在调试日志里留 `skipped_unchanged` 记录）；手动点击按钮的那次才会弹窗告知。
- 快捷键不在"任务状态"卡里展示，统一在"设置"窗口中查看与修改。

## 自定义组合键

- 在设置窗口里点一下按键区域就开始识别输入，按下组合键后松开即生效并写入 `config.json`。
- 规则是"**必须含 Win/Ctrl/Alt/Shift 辅助按键之一，且至少有一个字母键**"（字母键只允许 `a-z`，忽略大小写）。
- **数字键被刻意排除**：Windows 把 `Win+数字`/`Win+Shift+数字` 占作任务栏与窗口管理的原生快捷键，含数字的组合会被系统先吃掉，表现出来就是"注册成功却永不触发"。
- 识别期间全局快捷键会被暂停（否则按下的组合会真的触发动作）；组合不合法或注册失败时保留上一个可用组合，并给出可读的原因。

## 实现约定

- 组合键在内部用 `<win>/<ctrl>/<alt>/<shift>` + 字母表示；注册时把 `<win>` 翻译成 `pynput`的 `<cmd>`（`pynput` 没有 `Key.win`，但 `Key.cmd` 就是同一个键），组合匹配交回`pynput.keyboard.GlobalHotKeys`。
- 注册失败（被其它程序占用、缺少辅助功能权限、无图形环境）**不会中断应用**：失败结果收敛为可展示的状态，应用继续以"无快捷键"的方式工作。
- `pynput` 在后台线程监听键盘，因此回调只把请求投递到线程安全队列，由主线程执行实际动作。
