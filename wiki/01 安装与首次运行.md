# 01 安装与首次运行

## 运行要求

- **Windows 10 / 11（64 位）**：直接可用。
- **Linux**：需要桌面环境（系统得有图形显示服务）。
- **macOS**：全局快捷键需要先在「系统设置 → 隐私与安全性 → 辅助功能」里授权。

不需要预先安装 Python 或任何运行库：发布包已经把要用的东西都打进去了。

## 下载与启动

到发布页下载对应平台的包，解压到任意目录（例如 `D:\Tools\ArchiveManagement`），**双击解压出来的程序即可启动**（Windows 上是 `ArchiveManagement.exe`，Linux / macOS 上是对应的可执行文件）。

- 压缩包里的那一份是**免安装版**：不写注册表、不装服务，卸载就是删掉这个目录。
- 单文件版把整个程序打成一个可执行文件，双击即用；首次启动要先解包，所以会慢几秒。

首次启动会自动准备好数据目录与数据库，之后所有操作都在窗口里完成。

> 发布页上目前以 Windows 包为主，Linux / macOS 的包还在补齐编译流水线；三个平台的界面与操作完全一致。

## 数据放在哪里

默认放在系统标准目录：

| 内容                        | Windows                             | Linux                                                           | macOS                                              |
| --------------------------- | ----------------------------------- | --------------------------------------------------------------- | -------------------------------------------------- |
| 数据 / 配置 / 数据库 / 备份 | `%LOCALAPPDATA%\ArchiveManagement\` | `$XDG_DATA_HOME/ArchiveManagement`（通常是 `~/.local/share/…`） | `~/Library/Application Support/ArchiveManagement/` |
| 日志                        | 同上                                | 同上                                                            | `~/Library/Logs/ArchiveManagement/`                |

知道这些路径是为了备份配置、翻日志或彻底重置（见 [[10 常见问题与故障排查]]）。换新版本或删掉程序目录都不会动到它们。

## 首次运行会看到什么

- 首次启动是**空库**：主页三个分区（游戏库 / 游戏发现 / 游戏启停）里都没有内容，界面会给出各分区自己的空状态提示，而不是一片空白。
- 两种录入游戏的方式：顶栏的 **“+ 添加游戏”**（手动录入），或者去 **游戏发现** 分区扫描本机已安装的游戏后导入。
- 录入游戏后，**必须为它添加至少一个“原始存档位置”**，备份、定时任务与自动启停才会对这款游戏生效 —— 没有存档位置时它会被归到「待处理」，主页会明确显示"无有效存档路径"。
- 新建的游戏默认是**停用**状态：全局至多一款游戏处于启用状态，全局快捷键与定时备份都只作用于那一款。启用入口在主页的「启用/停用」按钮或游戏设置里，也可以交给 [[08 自动启停与监控队列]]。
