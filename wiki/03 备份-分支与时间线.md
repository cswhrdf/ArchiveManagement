# 03 备份、分支与时间线

## 一次备份是怎么落地的

- 先在同一级写**临时目录**，逐文件复制并计算 SHA-256，复制完再复核一遍；
- 全部成功后才**原子改名**成正式快照；
- 目标目录已存在时**直接失败，绝不覆盖已有备份**；失败或取消不会留下"看起来像完整备份"的半成品节点。

每个快照都记录内容哈希与文件清单，列表里的「已验证」标记来自清单的实际校验。

## 三种新建备份的方式

| 方式           | 位置                                  | 说明                                     |
| -------------- | ------------------------------------- | ---------------------------------------- |
| 立即创建备份   | 详情页工具栏 / 全局快捷键 `Win+Alt+S` | 以**当前节点**为父节点向下保存一次       |
| 从此处创建分支 | 选中任意节点                          | 以该节点为父节点分出新分支，并记录分支名 |
| 定时自动备份   | 游戏设置 → 定时备份                   | 见 [[05 定时任务与全局快捷键]]           |

快捷键只对**当前启用的那一款**游戏生效（停用或已归档的游戏只给一条提示），避免误按到不相关的游戏上。

## 内容没变就不重复备份

每次备份（手动 / 分支 / 自动 / 恢复前安全点）之前都会先与当前节点做内容比对：

- 存档一点没变 → **手动点击**弹窗告知"存档没有变化"；**自动备份**静默跳过（只在日志里留 DEBUG 记录）；
- 变了才产生新快照 —— 因此时间线里不会有大量内容完全相同的节点。

## 两个视图

- **分支图**（默认）：每个备份是一个**方框**，父子之间用曲线连起来；父框水平居中于它的子节点，所以"从哪儿分支、分出几支"一眼能看出来。自动备份只显示**最新一份**，不把图撑长。
- **时间线**：按时间倒序展示**全部**备份，并标明各自所属分支；恢复前安全点**只在这里出现**，不占分支图的位置。

### 分支图怎么看、怎么走

- **框里有什么**：名称（最多两行，放不下补省略号）＋ 一行小字（时间 · 手动/自动/安全点）。当前节点的小字前面有一个 `●`，它才是"下一次备份会接在这里"的那个节点；容量、文件数、描述在右侧的「选中备份」面板里看。
- **选中**：点一下框 → 框变成"淡底 + 强调色描边"（与列表/海报的选中是同一套表达），右侧面板与工具栏按钮跟着变。
- **收起 / 展开一棵子树**：有子节点的框**右下角**有一个小标记 —— `-` 表示展开着、`+` 表示已经收起了（与文件树里的加减号同一个意思），点它就在两者之间切换；选中某个节点后按 `空格` 或 `回车` 同样会收起它（再按一次放回去）。备份多的游戏靠这个把不关心的那几支收起来，一眼看到主干。
  - 折叠只改变**画面**：选中项、右侧面板与工具栏按钮一律不变（偷偷改选会让"恢复/建分支"作用到别的节点上，那是最危险的一类错）。
  - 藏起来多少会写在框上：收起后的框写着 `N 个后代`；如果被收起的那支里含**选中项**或**当前节点**（`●`），还会直接标出来（`含选中` / `含当前`），标记本身也会变成强调色。
  - 折叠**不会被记住**：它是"临时收拢一下看形状"的动作，切游戏、重新扫描或重启软件之后图又是完全展开的。
- **没有滚动条，靠"走"**：树一分叉就会比窗口宽，所以画面这么移动 ——
  - **按住空白处拖动**（拖到框上不会选中它，松手时的位移小于 4 像素才算"点了一下"）；
  - **方向键或 `WASD`**（先把鼠标点一下画面，键盘焦点才在图上；左手在 WASD 上时不用再去找方向键）；
  - **四条边中点的箭头**：点一下往那个方向走一步，**只在那个方向还有内容时才出现**（装得下就收起）；
  - **滚轮**纵向移动，**Shift + 滚轮**横向移动（触控板用户）。
- **已知代价**：图上的框不在 Tab 焦点链里，所以这个视图不能用 Tab 在节点间行走；键盘能做到的是**漫游**（方向键/WASD）与**收起/展开当前选中项**（`空格` / `回车`）。这里换取的同样是能看清分支形状。时间线视图与右侧面板仍然可以完整用键盘操作。方向键在本视图里已经被"漫游"占用，将来若要做"方向键在节点间走"需要先换绑定（例如 `Ctrl+方向键`）。

工具栏的来源筛选可以只看某一类节点（手动备份 / 自动备份 / 恢复前安全点）。每个节点还能「重命名 / 描述」（描述最多 200 字）。

## 删除备份

按分支树决定处理方式：

- 同一线路上的节点被删除 → 后续节点**自动上移**，不会变成孤儿；
- 删除**分支根节点** → 先提示"会连带删除该分支下的全部备份"，确认后整棵树一并删除。

## 备份目录与命名

- 备份根目录下按游戏分目录：`<游戏名称>-<短哈希>`，例如 `OuterWilds-3f9a2c1b`。
- 名称部分保留中文、替换文件系统的非法字符；短哈希区分同名游戏。
- 该目录名在首次备份时确定后**不再变化**，改游戏名不会搬动已有备份。

把备份带到另一台机器、或从别处的归档文件导入成新的游戏，见 [[11 导入与导出]]。
