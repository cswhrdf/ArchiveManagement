# 07 游戏发现与平台支持

「游戏发现」分区包含 **探测结果** 与 **监控目录** 两个页签，右上角固定是"重新扫描"。

## 探测结果

- 按平台扫描本机的安装清单、Windows 注册表与监控目录，把发现的游戏列为**待确认的候选**。
- **探测结果不会自动进入游戏库**：点"导入为游戏"才会新建游戏记录。探测到的是**安装目录**而不是存档目录，因此**不会自动登记成存档位置**。
- 也可以"忽略"（之后扫描不再提示，可随时在"已忽略"筛选里恢复）或"修正路径"。
- 列表**默认只看"待处理"**（这个页面的用途就是把发现的游戏收进库），可切换全部/已导入/已忽略；筛不到内容时给出的是该筛选下的空状态与各状态数量。
- 路径缺失、不是文件夹、不可读或属于高风险位置时给出明确状态（候选显示为不可导入）；游戏被卸载后再次扫描会刷新状态，而你的"已忽略/已导入"决定不会被覆盖。
- **平台官方工具默认隐藏**：`resources/excluded-games.json` 里列着公共运行库、录制工具这类"本身不是游戏"的程序；命中且仍待处理的候选直接标成**已忽略**（界面上就是隐藏状态），摘要里会写"平台工具已隐藏 N 项"。这份清单是**开发人员手工维护的固定数据**，程序只读不写。
- 单个来源出错（注册表不可读、清单损坏）只影响该来源：异常写日志并在摘要里计数，手动添加游戏与存档位置始终可用。

## 监控目录

用于覆盖"平台客户端路径自定义"或"根本不是平台游戏"的情况：

- 目录下的每个子文件夹都当作候选游戏（没有子目录时把目录本身当作候选）。
- 添加/编辑会校验路径存在、是文件夹、可读取，并拒绝盘符根目录与用户主目录；重复目录直接拦下。
- 支持添加、编辑、启用/停用与删除；**停用只是不参与扫描，不会删除记录**。

## 可信存档来源

存档位置**只接受可信来源**，绝不按路径模板瞎猜（猜错的路径一旦确认，恢复与删除会动到不该动的地方）：

- **Steam 云端同步清单** `userdata/<账号>/<appid>/remotecache.vdf`：已实现。清单里的相对路径用 `root` 编号还原成绝对路径（`1` 安装目录、`2` 文档、`3` `%LOCALAPPDATA%`、`12` `%LOCALAPPDATA%Low`），并且**只在与已安装清单求交集之后使用**（该文件包含已卸载但保留云同步状态的游戏）。
- **平台官方清单、游戏自带配置**：尚未接入，请手动填写。
- **Epic / GOG / Ubisoft / 监控目录**：接口保留但本期"暂不支持"，界面会直接说"需要手动添加"。
- 候选一律**先展示、经你确认**（导入对话框里可改可勾选）才写进存档位置，危险目标会被拦下。

## 封面与图标

- 取图顺序：**本地缓存 → 平台本地文件 → CDN 下载 → 缓存里的旧版本降级 → 游戏名前两个字占位**；走到哪一步、为什么失败都记日志。
- 列表行头像优先用**官方图标**（哈希来自本机 `appcache/appinfo.vdf` 的 `clienticon`），拿不到才用"封面裁方形"。
- 缓存放在应用缓存目录的 `artwork/` 下，**可随时整体删除**（可再生、不进备份、不进导出包）；删游戏会连它的封面图标一起清掉。
- 导入之后才在后台探测，补图完成界面会自动重绘。本地没有、网络不可用时回落占位，**不影响管理与备份**。
- **可以自己上传**：游戏管理窗口的「外观」一节里，封面与图标各能挑一张本地图片（也可单独「恢复默认」）。手动添加的游戏、或平台给不出图的游戏原本只有文字占位，这是唯一的取图途径。
  - 挑中的图会先校验再归一化：图标裁成方形 PNG（与官方图标同一条路），封面保留长宽比、长边压到 1200 以内；单张原图上限 12 MB。
  - 存的位置是**数据目录**下的 `artwork/<游戏 id>/`，与缓存分开 —— 缓存可以整体删除，而你挑的图不会被清理带走。
  - 取图顺序变为：**你指定的 → 本地缓存 → 平台本地文件 → CDN 下载 → 占位**。文件不能用时会当场说明原因（不是图片 / 太大 / 读不到 / 写不进）。
  - 删除游戏时，你指定的图与缓存图一起清掉。

## 重新扫描与"忽略"

重新扫描时会按磁盘现状重建探测结果: **这次没扫到、且不是已导入的候选项会被清掉**, 列表里
不会留下已经不存在的游戏(已导入的那几条会保留 —— 它们是游戏安装目录的来源)。

"忽略"是**按游戏名字**记住的, 与路径无关: 忽略过的游戏即使记录被清掉、之后重新装上再扫到,
也仍然直接算已忽略, 不会又跑回"待处理"让你处理第二遍。两个已知边界需要注意:

- 同名不同安装的游戏会**一起**被忽略;
- 游戏名变了(译名、加版本后缀)就对不上了, 那条已忽略的会重新回到"待处理"。

探测结果页右上角还有一个「清空结果」(需要确认): 一次清掉所有待处理/已忽略的记录, 已导入的
与忽略名单都保留, 然后重新扫描即可。
