# 09 配置文件与日志

## `config.json`

配置文件在应用数据目录（位置见 [[01 安装与首次运行]]）。**能在设置窗口里改的都建议在窗口里改**，手改文件只是为了批量调整或留档；无论哪种改法，程序**只写它认识的字段**：

| 字段                                         | 含义                                            | 默认值                    |
| -------------------------------------------- | ----------------------------------------------- | ------------------------- |
| `version`                                    | 配置文件格式版本                                | `1`                       |
| `theme`                                      | 主题：`system` / `light` / `dark`               | `system`                  |
| `language`                                   | 界面语言（只允许有文案资源的 locale）           | `zh-CN`                   |
| `hotkeys.save` / `hotkeys.branch`            | 全局快捷键，格式如 `<win>+<alt>+s`              | `Win+Alt+S` / `Win+Alt+Z` |
| `logging.debug`                              | 是否把基础操作也记进日志（DEBUG 级）            | `false`                   |
| `logging.max_bytes` / `logging.backup_count` | 日志滚动上限（默认 100 MB）与保留份数（默认 5） | 见默认值                  |
| `activation.auto`                            | 是否开启按进程自动启停                          | `false`                   |
| `ui.base_font_px`                            | 界面基准字号（基准单位，所有字号按它等比缩放）  | `16`                      |
| `window.width` / `height` / `x` / `y`        | 上次关闭时的窗口尺寸与位置（最大化关闭时不记）  | 空（用设计尺寸）          |

## 手改坏了会怎样

- **只写坏一项，就只修那一项**：非法取值落回默认值，**不认识的字段（含非设置相关的内容）直接删除**，其余自定义配置原样保留；处理过就把清理后的内容写回文件，并把原文件另存为 `config.json.invalid` 留档，界面上会告诉你有几处、是哪些字段。
- **整份读不出来**（JSON 语法坏了 / 顶层不是对象 / `version` 不认识）才**整份还原为默认值**，同样保留 `config.json.invalid`。
- **绝不让应用起不来**：配置读取永远交回一份可用配置；写回失败也只记日志，本次用内存里的取值继续跑。

## 日志

- 日志文件叫 `archive-management.log`，位置见 [[01 安装与首次运行]]（macOS 上在 `~/Library/Logs/ArchiveManagement/`）。
- 默认只记 INFO 及以上（备份、恢复、删除这类高风险操作）；打开设置里的「启用调试日志」才会把 DEBUG 级的基础操作也写进去 —— 排查问题时才需要，平时不必开。
- 日志按大小滚动（默认单文件 100 MB、保留 5 份），在设置里可以看到当前开的是哪一级。
- **日志里不写凭据与文件内容**，路径按脱敏规则处理。
- 给源码仓提 issue 时请附上相关时段的日志（见 [[10 常见问题与故障排查]]）。
