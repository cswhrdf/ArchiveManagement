# 06 游戏库与分类筛选

游戏主页是打开软件后的默认页，顶部分区页签在 **游戏库 / 游戏发现 / 游戏启停** 之间切换。

## 视图与筛选

- 视图：**全部游戏 / 最近活跃 / 待处理 / 已归档**。
  - **待处理**只包含真正卡住不能用的游戏：**还没配置存档位置，或者存档路径已失效**。已经配好可用位置但还没备份过的游戏**不算**待处理（它随时可以备份），这类状态由"未备份"与"长期未更新"分类表达。
  - "最近活跃" = 14 天内有备份或变更。
- 筛选：平台、分类、搜索词；搜索结果与筛选条件可以叠加。
- 计数口径一致：下拉框里每个选项后面的数字是"在当前其它筛选条件不变的前提下选中它会有多少条"，因此不会出现"选了之后是空的"。

## 列表模式与海报模式

- **列表模式**按列对齐展示：名称、平台、存档位置数、备份数、最近备份时间、最近活动时间与状态标签（平台 / 备份状态 / 风险 / 归档 / 自定义标签）。路径不可用时状态标红；**没有关联存档位置时备份那一项显示"无有效存档路径"，而不是"未备份"**。排序为"待处理在前 → 最近活动倒序 → 名称"。
- **海报模式**用卡片展示竖屏封面：右下角是备份数量角标，左下角是"启用中"的绿点（停用的游戏不加任何标记，因为停用是常态）。**没有关联存档位置时角标显示"无有效存档路径"**。两个标记只在**真的显示封面图**时带一层圆角底衬 —— 图上什么颜色都有可能，没有底衬会看不清。
- 名称是唯一长度无法预期的一列，它拿"剩下多少算多少"的宽度（窗口拉宽就能多看到几个字），超出补省略号；海报卡片里的名称最多折两行。完整名称在游戏设置里看。
- 底栏右侧是"每页 + 第 x/y 页 + 上一页/下一页"，每页条数可选 **30（默认）/60/100/200**；不需要翻页时按钮自动置灰。

## 自定义标签与归档

- **编辑标签**：一行一个，行数有上限，保存时自动去空白、去重、截断，并**剔除中英文逗号**（数据库按逗号拼接保存，允许逗号会让一个标签在往返后变成两个）。
- **归档**：停用该游戏 + 暂停它的定时备份，只保留删除/导出/取消归档/打开详情（见 [[02 游戏与存档位置]]）。

## 展示偏好会被记住

视图、平台、分类、搜索词与展示偏好（列表/海报、每页条数）保存在数据库的 `home_state` 表（单行，带格式版本号）：关掉软件再打开还是上次看到的样子。旧版本（格式不同）的记录会被忽略并回落默认值，而不是让界面读到无法解释的取值。

切换深/浅主题时主页会用新调色板重建一次，**当前分区、筛选条件、页码与选中项都会保留**。
